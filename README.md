### CookBook

Um aplicativo de estudo desenvolvido para praticar Jetpack Compose, consumo de API, exibição de listas, navegação entre telas e uso de BottomSheet para detalhes.
O app carrega uma lista de sobremesas a partir de uma API e permite visualizar informações detalhadas de cada item. 

### Funcionalidades
* Listagem de sobremesas carregadas via API
* Indicador de carregamento enquanto os dados são obtidos
* Tela de detalhes exibida em formato BottomSheet
* Navegação por ID usando NavController
* Interface moderna com Material 3 + Compose
* Layout responsivo e adaptado ao recorte da status bar

### Tecnologias Utilizadas
* Kotlin
* Jetpack Compose
* Material Design 3
* Navigation Compose
* Retrofit
* ViewModel
* Coroutines + Flow
* Coil
* BottomSheet em Compose
